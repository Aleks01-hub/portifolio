# Portfólio — Alex Silva

Portfólio pessoal em HTML e CSS, com tema azul-marinho, detalhes em azul e layout responsivo.

## Visualizar
Abra `index.html` no navegador. Não é necessário instalar dependências.

## Personalizar
- Edite textos e links em `index.html`.
- Ajuste cores, layout e efeitos em `style.css`.
- Troque o link genérico do LinkedIn pelo endereço do seu perfil.
- Confira se os repositórios e descrições dos projetos continuam corretos.

## Publicar no GitHub Pages
1. Crie um repositório chamado `portfolio` no GitHub.
2. Envie `index.html`, `style.css` e `README.md` para a raiz do repositório.
3. Entre em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde o GitHub Pages publicar o site e abra o endereço exibido.
